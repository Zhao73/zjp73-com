支持

DeskAgent Mobile 支持

遇到问题可以先按下面顺序检查，也可以邮件联系 support@zjp73.com。

首次安装

  1. 在 Mac 上打开 下载页。
  2. 下载并解压 DeskAgentLink-macOS.zip。
  3. 打开 DeskAgent Link，并保持窗口运行。
  4. 在 iPhone App 中点击“扫码绑定 Mac”。

扫码后连不上

  • 确认 Mac 和 iPhone 在同一 Wi-Fi，或都连接到同一个 Tailscale/VPN。
  • 确认 DeskAgent Link 仍然打开。
  • 如果二维码过期，请在 Helper 里重新生成并扫码。
  • 真实 iPhone 不能使用 127.0.0.1，请使用 LAN 或 Tailscale 地址。

登录问题

如果提示需要登录，请按 App 打开的授权页面完成 ChatGPT 登录。登录凭据保存在 Mac，不会保存在本网站。
