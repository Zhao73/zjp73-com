# DeskAgent site

Static site for `https://zjp73.com/deskagent/`.

The site is multilingual. It defaults to the browser/system language and currently supports Chinese, English, and Japanese via `i18n.js`.

Cloudflare Pages setup:

- Repository: `Zhao73/zjp73-com`
- Root directory: repository root
- Build command: none
- Output directory: `.`
- Public path: `https://zjp73.com/deskagent/`

Required public URLs for App Store metadata:

- Marketing URL: `https://zjp73.com/deskagent/`
- Support URL: `https://zjp73.com/deskagent/support/`
- Privacy Policy URL: `https://zjp73.com/deskagent/privacy/`
- Terms URL: `https://zjp73.com/deskagent/terms/`
- Helper download: `https://zjp73.com/deskagent/download/`
