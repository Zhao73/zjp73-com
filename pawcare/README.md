# PawCare public website

Static microsite for `pawcare.zjp73.com`.

## Pages

- `/` -> product overview
- `/privacy/` -> privacy policy
- `/support/` -> support page
- `/terms/` -> terms of use

## Deployment assumptions

- Cloudflare Pages or another static host can use this directory as the site root.
- Suggested Pages root directory: `pawcare`
- Framework preset: `None`
- Build command: empty, or `exit 0`
- Build output directory: `.`
- Custom domain: `pawcare.zjp73.com`

The copy intentionally describes PawCare as a pet health record notebook with reminders, medical records, photo/PDF/OCR organization, local sorting, and Premium export/OCR features. It does not claim to diagnose, treat, prescribe, or replace veterinary care.
